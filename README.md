# Chess Program
### Chess Application that lets two people play chess in a CLI

this program provides a platform, much like Chess.com or Lichess, for two humans to play chess in a Command-Line Interface by via coordinates\
#### <ins>Features:</ins>
- Board Representation
- Turns
- Legal Move Generation
- Captures
- Check Detection
- Checkmate
- Stalemate
- Castling
- Castling Rights
- En Passant
- Pawn Promotion
- King Safety Checks
- Half Move Clock
- Full Move Number
- FEN
